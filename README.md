# General Tyre Auto Parts & Inventory Management System

A dedicated spare parts and automotive component inventory tracking system built with **PHP** and **MySQL**.

## Key Features
- **Parts Cataloging**: Track automotive spare parts with serial numbers, model compatibility, and pricing.
- **CRUD Operations**: Add new parts, update stock information, view product specs, and manage inventory levels (`index.php`, `edit.php`).
- **Image & Documentation Records**: Store and reference component diagrams and part photos.
- **Stock Tracking**: Maintain updated inventory balances to prevent out-of-stock scenarios.

## Technology Stack
- **Backend**: PHP
- **Database**: MySQL (`parts.sql`)
- **Frontend**: Responsive HTML5 & CSS3

## Setup Instructions
1. Import `parts.sql` into your MySQL database.
2. Configure database credentials in `connection.php`.
3. Access the portal via your web browser.
